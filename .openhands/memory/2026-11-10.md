

## BerryAPI cosmetic C ABI — bound end to end (PR #176 + preloader PR #33)

**Submodule pin trap (recurring).** The parent pin was `d43b1c1`; the preloader's own `main`
(`e31b8b2`, merge of PR #32) is **not** a descendant of it — they forked. `main` carries
`nativeCloseUnusedModuleHandles` **without** the cosmetic exports; `d43b1c1` has the cosmetic
exports' prerequisite but not the cosmetic bind. So neither pin alone satisfies
`JniBindingParityTest`. Fix: branch off the submodule `main` and cherry-pick the cosmetic bind
commit onto it (one clean commit), which gives both. Verify with
`git merge-base --is-ancestor <pin> origin/main` — it can be NO even when the pin looks recent.

**BERRY cosmetic ABI is version 1, independent of the global `BERRY_ABI_VERSION` (8).**
Symbols: `BERRY_GetCosmeticApi`, `BERRY_CosmeticStructSize`, `BERRY_CosmeticAbiVersion`,
`BERRY_CosmeticBoneReaderStructSize`. Mirror struct sizes: `BerryCosmeticAssetC` 520, stats 56,
bone transform 44, bone reader 32, `BerryCosmeticApi` 160. Slots 0-7
(None/Head/Back/Shoulders/Body/Trail/Effect/Emote); statuses 0-12. The preloader cannot include
`berry/cosmetic_c.h` (it `dlopen`s), so it mirrors the struct and checks `size`/`abi_version`
before touching a pointer.

**Three gates that catch "compiles but silently broken" here** (all three failed first time):
1. `NoSilentCatchTest` — an empty catch body fails the build even with a comment inside; the
   documented escape is the exact substring `best-effort` in the body.
2. `TranslationCoverageTest` — a new user-visible string must be translated in all 10 locales or
   marked `translatable="false"`; it is NOT auto-baselined.
3. `AgentsDocTest` — a new `docs/agents/*.md` must be listed in `AGENTS.md` or the build fails.

**The bone half is not done.** `set_player_model_hook` needs the preloader to resolve the per-build
player-render target (signature scan) and install the detour itself; the JNI entries only report its
state. Until then the catalog/loadout/presets are live but **nothing renders** — do not claim the
cosmetics render in-game.
