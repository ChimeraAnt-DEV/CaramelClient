## CurseForge tab (CaramelCurseForgeTab + CurseForgeSections + core.curseforge)
- **The tab must browse before it is asked to.** For two releases the CurseForge screen was blank on entry: it only called the API from the Search button, so a first-time visitor saw an empty page and concluded the tab was broken. `LaunchedEffect(state.curseForgeSection)` now runs the default listing when nothing has been searched and nothing is on screen. Do not "simplify" it back into the search button, and keep the guard (`curseForgeSearched` / results / busy) or every recomposition re-fires the request.
- **An empty query is a browse, not an error.** `CurseForgeClient.searchUrl` only adds `searchFilter` when the query is non-empty, and `classId` only when it is above zero. `CurseForgeSectionsTest` pins both, because a stray `searchFilter=` returns nothing and looks exactly like "CurseForge has no content".
- **Sections are the API's own Bedrock classes, read from the live catalogue** (`GET /v1/categories?gameId=78022`): Add-ons `4984` (subcategories Maps / Texture Packs / Skins / Players / Mobs / Data Packs / PvP / Realistic / Simplistic / Miscellaneous / Themed), Maps `6913`, Skins `6925`, Texture Packs `6929`, Scripts `6940`. A transposed digit does not fail loudly — it returns an empty or unrelated section — so `CurseForgeSectionsTest` pins every id.
- **Sorting is requested and then applied again.** Everything asks for `sortField=6` (total downloads) descending, and `sortedByDownloads` re-sorts the page before it reaches the list. The API is asked for the ranking; the client does not trust the order it gets back. The sort is stable, so equal download counts keep the API's order instead of jumping between recompositions.
- **A result row shows the project's own picture.** `logo.thumbnailUrl` (e.g. `https://media.forgecdn.net/avatars/thumbnails/...`) goes through `CaramelAvatarLoader`, the same bounded cache the account avatar uses, so scrolling a listing does not re-download. The CurseForge mark is the fallback for a project with no logo — it must not be drawn in place of one, which is what made every texture pack look like the same card.
- **The key is not the user's problem.** `BuildConfig.CURSEFORGE_API_KEY` has a default; the key field is only reachable from Developer mode (`CurseForgeKeyStore` holds a device override). `CurseForgeClient.describeFailure` maps 401/403/429 to something a person can act on rather than the raw status.
- **Downloadable means a file URL came back.** `CaramelCurseForgeItem.downloadable = downloadUrl.isNotEmpty()`; the row disables Download otherwise instead of starting an empty transfer.
