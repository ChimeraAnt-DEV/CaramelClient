## Splash screen (ui.activities.SplashActivity + drawable/ic_chimera_ant)
- The splash mark is the **vector** `ic_chimera_ant`, tinted to the user's accent in `applySplashTheme` (`setImageTintList`). Orbit ring, orbit dot and the halo are `GradientDrawable`s rebuilt per accent, with the static `bg_orbit_ring`/`bg_orbit_dot`/`bg_logo_glow` drawables only as the pre-tint fallback — those fallbacks carry brand tokens now, not the old green/cyan.
- **The backdrop is a bundled key-art image, not a flat gradient and not a live 3D scene.** `SplashActivity` decodes one of the bundled key-art images (`SplashBackgroundRegistry`/`SplashBackgrounds`) and shows the logo lockup over it. The old animated backdrop — a star field, parallax terrain, floating voxel cubes, a turntable voxel island and a wordmark shatter — is **removed**: it rebuilt a particle system, a terrain mesh and several sprites every frame on the cold-start path, for a screen visible for a couple of seconds. The classes that drew it (`SplashSceneView`, `SplashIsland`, `SplashWorld`, `SplashParticles`, `WordmarkShatter`, `ShatterPlan`, `OreLoaderLayout`) no longer exist.
- **The warm-up is time-budgeted, not time-fixed.** Progress comes from real milestones (`SplashInit`) and the display is `min(real, paced)` (`SplashTimeline`), so a fast start still gets a watchable beat and a slow one holds at its current progress instead of looping or looking stuck. App usability is never blocked behind a fixed-length animation.
- The sequence also runs a slow **halo breathe** (`startLogoBreathe`, a 2.4s reverse scale/alpha ValueAnimator with a start delay so it does not fight the entrance) so the lockup never looks frozen on a slow warm-up.
- The sequence animates: glow scale-in, mark scale-in, orbiting dot (`startOrbitAnimation`, 3s loop), halo pulse (`startGlowPulse`), progress tween → `navigateToMain`. Keep new motion on these ValueAnimators rather than swapping in a static PNG.
- All three tints (`orbitRing`, `orbitDot`, `logoGlow`) are accent-derived; if a colour looks off it is the accent resolver, not the drawable.
- **The loader is one rotating arc.** `SplashSpinner` draws a single spinning arc on a hardware-accelerated canvas (one draw call) instead of the old ore block/pickaxe sprite grid. Its geometry is trivial enough to need no pure model class; the timing rule (`SplashTimeline`) is the part that is unit-tested.
